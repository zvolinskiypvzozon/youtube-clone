## Фронтенд

**Сделано** (`86b03bd`, CI — `15ac80e`, docs — `d4fccce`).

**Стек:**
- React Router 7.18.5. Сначала был 6.x, перешли после аудита (см. ниже).
- TanStack Query 5.62.
- Vitest 3.2.7 + Testing Library.
- ESLint 10, без `eslint-plugin-react`; правила безопасности — свои, через `no-restricted-syntax`.
- Типы API генерируются из OpenAPI (`npm run gen:api` → `src/api/schema.d.ts`).

**Экраны и поведение:**
- **Каркас:** шапка, боковое меню, меню пользователя, страницы-заглушки для дня 8, 404.
- **API-клиент:** `X-CSRF-Token` из cookie `csrf`, единый формат ошибок `ErrorOut`.
- **Повторы:** 4xx не повторяются. Чтение — 429/503 до 3 раз с учётом `Retry-After`
  (от 1 до 30 с). Изменяющие запросы — только 429: 503 мог прийти уже после записи.
- **Вход, регистрация, выход:**
  - смена пользователя сбрасывает кэш и отменяет запрос `/me`, начатый до входа;
  - 401 у вошедшего пользователя — переход в режим анонима, без цикла запросов;
  - `/me` перепроверяется при возврате во вкладку;
  - выход с ошибкой не показывает «вы вышли».
- **Возврат после входа** (`safeReturnPath`): только путь этого сайта. Адрес хранится
  в состоянии навигации, не в URL.
- **Лента:** подгрузка по курсору через `IntersectionObserver`.
- **Поиск:** debounce 300 мс (решение 2026-11-10), запрос — в URL.
- **`UserText`** — единственный способ вывести пользовательский текст:
  - текстовым узлом;
  - `dir="auto"` + `unicode-bidi: isolate`;
  - обрезка переполнения против «zalgo».

  Закрывает Low из аудита шага 1 дня 6.
- **ESLint** запрещает небезопасный HTML: `dangerouslySetInnerHTML` (и обходы через спред,
  `createElement`, `Object.assign`), `innerHTML`, `srcDoc`, `eval`, литералы `javascript:` и др.
  `href`/`src`/`poster` из выражений — только через `safeUrl()`. Отключить правило комментарием
  нельзя (`noInlineConfig`). Полный список — `docs/security.md`, раздел «Фронтенд (день 7)».
- **CI:** линт, Vitest, `npm audit --omit=dev --audit-level=high`.
