# ADR 0006: Модель видимости видео и единая политика доступа

- Статус: принято
- Дата: 2026-11-07

## Решение

Видимость определяют три независимых признака видео:

| Признак | Значения | Кто меняет |
|---|---|---|
| `visibility` | `public`, `unlisted`, `private` | владелец |
| `status` | `uploading`, `processing`, `ready`, `failed` | система |
| `moderation` | `ok`, `hidden` | модератор/админ |

Кто видит видео:

| Зритель | public | unlisted | private | hidden модерацией |
|---|---|---|---|---|
| Аноним / чужой | лента, поиск, канал, ссылка | только по ссылке | нет (404) | нет (404) |
| Из списка допуска (`video_access`) | да | да | по ссылке и в «Доступные мне» | нет |
| Владелец | да | да | да | да, с пометкой «Скрыто модератором» |
| Модератор / админ | да | да | да | да |

- Видео со статусом не `ready` видят только владелец и модераторы/админы.
- Вся логика собрана в одном модуле `app/services/policies.py`:
  - `can_view(viewer, video) -> bool` для единичных запросов;
  - `visible_videos_filter(viewer)` — SQL-условие для лент, поиска, канала и плейлистов.
- Чужим отвечаем 404, а не 403: так не раскрывается факт существования приватного видео.
- Комментарии, лайки и счётчики доступны только тем, кто может видеть видео.

## Последствия

- Новый путь выдачи видео без политики — дефект, ловится ревью (агент `reviewer`)
  и матричными тестами.
